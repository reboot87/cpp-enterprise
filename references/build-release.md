# 构建与发布

## 1. 构建系统

- CMake ≥3.20 + `CMakePresets.json`;工具链用 toolchain 文件。
- 源码树外构建(`build/` 不进版本库);IDE 工程是生成产物。
- 构建脚本单一来源,CI 与本地使用同一 preset,禁止"CI 专用参数"。
- 交叉编译必须有 toolchain 文件与 CI 任务。

## 2. 构建类型

| 类型 | 用途 | 要求 |
|---|---|---|
| Debug | 开发 | 断言开启,sanitizer |
| RelWithDebInfo | 测试/预发 | 优化 + 符号 |
| Release | 发布 | NDEBUG,硬化选项,无完整符号 |

- 三种类型都必须能编译通过。
- Release 与 Debug 行为差异仅限断言与日志级别,不得有功能分支。
- `/MT` 与 `/MD` 全工程一致;与第三方库的 CRT 必须匹配。

## 3. 编译选项基线

- 告警:`-Wall -Wextra -Wpedantic -Wconversion -Wshadow`,`/W4 /permissive-`;CI `-Werror`。
- 硬化选项见 `security.md` §6。
- LTO 仅在 Release 且经过性能验证后启用;PGO 需可复现的 profile 流程。
- 发布包禁止 `-march=native`;按目标 CPU 基线选择 `-march=x86-64-v2` 之类。
- 固定编译器与标准库版本,记录在构建信息里。

## 4. 依赖获取

- manifest + lock(vcpkg/Conan)或 FetchContent + `URL_HASH`;禁止 latest。
- 支持离线构建:依赖缓存/镜像,不依赖构建时外网。
- 依赖目录不进源码树(`third_party/` 由构建拉取或子模块锁定)。

## 5. 产物

- 产物目录结构固定:`bin/`、`lib/`、`include/`、`share/`。
- 二进制内嵌版本与构建号,启动日志可查。
- 调试符号单独归档,发布包不含完整符号。
- 可复现构建:同输入同工具链 → 同哈希;CI 定期验证。
- 去除不确定性来源:`__DATE__`/`__TIME__`、绝对路径、时间戳、无序容器遍历、并行链接顺序;必须保留的写入构建元数据。

## 6. 版本与兼容

- SemVer;公开 API/ABI/配置格式/协议都要版本化。
- 每次发布有 CHANGELOG:新增、变更、修复、破坏性变更、迁移步骤。
- 弃用窗口 ≥1 个次版本;废弃项在编译期/运行期给出警告。
- 明确支持窗口(如最近 3 个次版本),旧版本修复策略写清楚。

## 7. 发布物

- 产物签名或至少发布 SHA-256;附 SBOM 与 NOTICE。
- 从"构建一次"的产物部署到所有环境,禁止各环境重新构建。
- 发布前跑 `assets/release-checklist.md`。

## 8. 部署与回滚

- 灰度/金丝雀:先小流量,看错误率与 p99,再全量。
- 回滚路径演练过,目标 ≤ 5 分钟;数据库变更必须有回滚或前滚方案。
- 特性开关控制新行为;开关有生命周期,上线稳定后删除。
- 数据库迁移:前向兼容(旧代码可读新 schema 一个版本),禁止破坏性一步到位。

## 9. 故障与应急

- 发布后观察窗口 ≥30 分钟,关键指标(SLO)达标才算完成。
- 事故有 runbook(见 `observability.md`),发布回滚步骤写在 runbook 里。
- 事后复盘产出:时间线、根因、改进项与负责人。

## 10. 代码生成

- IDL/proto/schema 入库;生成代码放 `generated/`,禁止手改。
- 生成步骤进构建;CI 重新生成并校验 diff 为零。
- 生成代码的告警抑制只作用于该目录,不全局关闭。
- 生成代码参与评审(至少看接口与命名),但不逐行人工维护。
- 生成器升级单独提交,不与业务改动混在一起。

## 11. 支持与升级策略

- 明确支持矩阵:OS 版本、编译器、标准库、依赖主版本。
- 只在矩阵内构建与测试;矩阵外不承诺。
- 编译器/OS 每年至少评估一次,EOL 前完成迁移。
- 安全补丁策略:严重问题为旧版本提供补丁或强制升级路径。
- LTS 版本与支持窗口写进 README/CHANGELOG。
- 升级前跑全量测试、sanitizer 与压测,记录行为差异。

## 12. 反模式

- 手改生产二进制。
- 构建产物不签名、不可追溯。
- 各环境重新构建导致行为不一致。
- 发布与数据库迁移同时不可逆。
- 特性开关永久滞留,组合爆炸。
