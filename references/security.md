# 安全

## 1. 信任边界与威胁建模

每个对外功能先画信任边界:入口(网络、文件、命令行、环境变量、IPC)、资产(数据、密钥、算力)、攻击者能力。

STRIDE 逐项过:

| 威胁 | 问什么 | 典型控制 |
|---|---|---|
| Spoofing | 身份可伪造吗 | 认证、签名、mTLS |
| Tampering | 数据可篡改吗 | 完整性校验、签名、只读 |
| Repudiation | 操作可抵赖吗 | 审计日志、时间戳 |
| Information disclosure | 会泄露什么 | 最小化、脱敏、加密 |
| Denial of service | 能被打瘫吗 | 限流、上限、超时 |
| Elevation of privilege | 能越权吗 | 鉴权、最小权限、沙箱 |

新端点、新解析器、新依赖,提交时附威胁建模结论(模板 `assets/threat-model.md`)。

## 2. 认证与授权

- 默认拒绝;未明确授权的路径一律拒绝。
- 认证与授权分离;做资源级授权,不只看角色。
- 口令用 Argon2id/bcrypt/scrypt 加盐;禁止 MD5/SHA1/裸 SHA256 存口令。
- token 校验:算法白名单(拒绝 `none`)、过期、受众、签发者;比较用恒定时间。
- 令牌有生命周期与撤销;不把令牌放 URL。
- 限流按身份和 IP 双维度;登录失败不回显"用户是否存在"。

## 3. 加密与随机

- 只用成熟库(AEAD:AES-GCM/ChaCha20-Poly1305);禁止自研算法与模式。
- 随机数用 CSPRNG;禁止 `rand()`、时间戳做种子。
- TLS ≥1.2,禁用弱套件;证书校验默认开启,禁止"临时关闭 verify"进主干。
- 密钥不入代码、镜像、日志、配置库;从 KMS/secret store 注入,支持轮换。
- 敏感内存用后清零;避免进入 core dump/swap(平台支持时 `mlock`)。

## 4. 输入与输出

- 边界校验:长度、类型、范围、数量、编码;解析前先限长。
- 路径:规范化后校验前缀,拒绝 `..`、绝对路径、符号链接逃逸;POSIX 用 `O_NOFOLLOW`。
- 命令:禁止拼 shell;用参数数组;必须拼时走白名单。
- SQL/查询:参数化;禁止字符串拼接。
- 输出按上下文编码(HTML/JSON/SQL/日志),防注入。
- 反序列化:限制嵌套深度与大小,拒绝任意类型多态反序列化。

## 5. 平台安全

- Windows:`SetDefaultDllDirectories`、`LoadLibraryEx` 绝对路径、签名校验;服务最小权限;`/guard:cf`。
- POSIX:`umask`、`O_NOFOLLOW`、setuid 后降权、`mkstemp`。
- 通用:不在世界可写目录创建可执行文件;日志不跟随符号链接。

## 6. 编译与链接硬化

| 平台 | 选项 |
|---|---|
| GCC/Clang | `-fstack-protector-strong -D_FORTIFY_SOURCE=2 -fPIE -pie -Wl,-z,relro,-z,now -fcf-protection` |
| MSVC | `/GS /guard:cf /DYNAMICBASE /NXCOMPAT /sdl /HIGHENTROPYVA` |

- 硬化选项必须进 Release 构建,CI 检查实际生效(ELF/PE 属性)。
- `-D_FORTIFY_SOURCE=2` 需要开优化;Debug 下要么配合 `-O1`,要么关闭该宏并单独记录。
- 不发布带完整调试符号的二进制;符号单独归档。

## 7. 依赖与供应链

- 许可证白名单:MIT/BSD/Apache-2.0 可直接用;GPL/AGPL/LGPL 需法务 + ADR;生成 NOTICE 随包。
- SBOM 随发布物;CVE 扫描每次构建。
- 修复 SLA:严重 ≤7 天,高危 ≤30 天,中危下个版本。
- 第三方二进制校验哈希/签名;构建来源可追溯(SLSA 或等价 provenance)。

## 8. 安全测试与评审

- SAST、secret scan、依赖扫描进 CI。
- 外部输入解析器必须 fuzz;认证/协议实现测畸形输入。
- 对外暴露面变更需要安全评审;按风险每年至少一次渗透测试。
- 漏洞披露渠道与响应流程写入仓库。

## 9. 日志与隐私

- 不记录口令、token、密钥、完整证件/卡号;必要字段脱敏或哈希。
- 数据分级(公开/内部/机密),按级别限制日志与导出。
- 留存期限符合合规要求,删除路径可执行。

## 10. 依赖混淆与来源验证

- 私有包用作用域/私有 registry;禁止公共源与私有源同名回退。
- 新增依赖检查 typosquatting,人工确认来源与维护者。
- 禁止通配版本与 `latest`;锁文件完整提交。
- 优先源码构建;用二进制时校验哈希/签名。
- CI 拉取依赖用最小权限令牌,禁止在日志回显令牌。

## 11. 审计日志与隐私清单

- 安全事件必须留审计轨迹:登录成功/失败、权限变更、密钥访问、配置变更、数据导出。
- 审计日志只追加、带时间戳与主体;有保留期限和访问控制,关键场景防篡改。
- 维护 PII 清单:字段、来源、用途、保留期、访问者。
- 新功能收集个人信息前完成隐私影响评估(PIA)。
- 数据删除请求有可执行路径并留记录。

## 12. 反模式

- 自研加密、随机、编码。
- 关闭证书校验"先跑通"。
- 用时间戳/自增 ID 当令牌。
- 密钥写进 config、Dockerfile、CI 明文变量。
- 只在前端校验。
- 捕获异常后当成功返回。
