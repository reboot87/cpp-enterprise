# 降级矩阵

每一行必须能落到监控信号和开关;没有降级方案的写"直接失败"并注明影响。

| 依赖 | 故障类型 | 检测信号 | 超时/阈值 | 降级动作 | 核心功能影响 | 用户可见表现 | 恢复条件 | 开关 |
|---|---|---|---|---|---|---|---|---|
| | 超时 | | | | | | | |
| | 连接失败 | | | | | | | |
| | 错误率升高 | | | | | | | |
| | 慢响应 | | | | | | | |

功能分级:

| 级别 | 定义 | 失败时 |
|---|---|---|
| 核心 | 无它不可用 | 快速失败并告警 |
| 重要 | 降级可用 | 返回缓存/部分结果 |
| 非核心 | 可关闭 | 静默关闭 + 记录 |

规则:

- 降级动作必须可逆,且有明确恢复条件。
- 禁止静默降级:必须计数、打点、可查。
- 每个降级路径有测试或演练记录。
