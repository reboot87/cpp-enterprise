# 评审清单与完成定义

## 完成定义(DoD)

- 全平台矩阵编译通过,零新增告警
- 单测/集成测试通过,新增或变更行覆盖 ≥90%
- 静态检查、格式、SAST、secret scan 零新增
- 文档与 CHANGELOG 已更新
- 安全与性能影响已评估并记录

## 设计

- [ ] 改动落在既有模块/扩展点,影响面 ≤6 文件
- [ ] 依赖方向单向,无循环依赖
- [ ] 状态有单一所有者,启动/关闭顺序已考虑
- [ ] 接口变更已版本化,错误码已登记,弃用有窗口

## 正确性

- [ ] 错误路径有处理,不吞异常
- [ ] 边界已覆盖:空、超长、越界、并发、重复调用
- [ ] 资源上限与超时齐备

## 安全

- [ ] 输入在信任边界校验
- [ ] 鉴权失败默认拒绝
- [ ] 无密钥/口令/PII 进入日志、代码或配置
- [ ] 外部解析器有 fuzz 或畸形输入用例

## 平台

- [ ] 除 `handle.h` 外,公共头无 OS 头与平台宏
- [ ] 平台实现同名成对,含哨兵
- [ ] Windows 目标在所有配置定义 `UNICODE`/`_UNICODE`,Win32 调用用显式 `...W`
- [ ] 句柄/大小/时间类型可移植(不用 `int`/`long` 存句柄)

## 性能

- [ ] 热路径有基准或 profile 证据
- [ ] 无无界队列、缓存、分配
- [ ] 持锁期间不做 IO、分配、日志

## 测试

- [ ] 新逻辑覆盖失败路径
- [ ] bug 修复带回归用例
- [ ] 无 `sleep`、顺序依赖、共享状态

## 并发

- [ ] 线程/任务有名字,线程池与队列有界
- [ ] 阻塞调用可取消,超时有截止时间
- [ ] 持锁期间无 IO/分配/日志/回调
- [ ] 关闭路径无孤儿线程,有截止时间

## 可维护

- [ ] 命名与布局符合规范
- [ ] 注释为中文,标识符/宏/路径保持英文
- [ ] 注释解释为什么;公开头有契约
- [ ] 无死代码,无无 issue 的 TODO
